Project

Open or create a project.

Landings

Skidders route each bunch to the cheapest landing. Assign a truck count per landing to split the fleet; leave blank to use the shared fleet. Loader/processor fleets are assigned in the Machines panel.

Stand & retention

Click trees with the Retain tool. Retained trees stay in the stand and are excluded from the derived harvest.

Machines

Machine role edits are stored in the project. Applying a system preset rebuilds the fleet while preserving terrain, retention, landings, roads, trucks, and economics. Save afterward to run it.

Policy effects

Cycle multipliers, breakdown risk, break policy, grade caution, and damage risk are translated into the next run. Elevated damage risk downgrades a share of sawlog volume to pulp.

Machine specs

Blank values use the scenario/default machine specification. Overrides apply to the selected machine.
