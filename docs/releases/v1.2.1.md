# FHOPS v1.2.1

- GitHub release: https://github.com/UBC-FRESH/fhops/releases/tag/v1.2.1
- PyPI: https://pypi.org/project/fhops/1.2.1/

FHOPS 1.2.1 is a patch release on the 1.2 line. It adds the Scenario Studio
comparison and salvage surfaces, CTL forwarder/harvester refinements, FEMIC
ground-summary support, and the verified dual 3D replay workflow.

```bash
pip install fhops==1.2.1
# optional web UI
pip install 'fhops[web]==1.2.1'
# optional DEM/road and LiDAR tooling
pip install 'fhops[lidar]==1.2.1'
```

## Highlights

### Scenario Studio

- Full-tree ↔ CTL system presets, including custom machine IDs and one
  loader/processor per landing.
- Operator-policy translation for cycle time, breakdown risk, grade caution,
  and damage-risk product downgrade.
- Run comparison page with KPI, machine, truck, landing, and economics views;
  interactive charts and deterministic JSON export.
- Run-history comparison launcher with shareable project/run query parameters.
- Product mix (sawlog/pulp), product prices, revenue, cost per m³, and net
  margin in the comparison view.
- Read-only salvage-age overlay in Studio and the comparison page, backed by the
  packaged `fhops.salvage` curve library.

### CTL and ground-system refinements

- Harvester/forwarder role propagation and machine-spec generation.
- Calibrated forwarder productivity, distance-varying final-felling regression,
  and calibrated load/unload timing.
- Terrain/road validation, grade-aware routing, and multi-landing fleet
  assignment remain available through the Studio workflow.

### Salvage shelf-life

- New `fhops.salvage` package with typed `salvage.decay.v1` curves, provenance,
  boundaries, and advisory product windows.
- Published Prestemon & Holmes (2008) mixed-conifer fire-killed retention curve.
- `fhops report salvage-shelf-life` joins a storage-age CSV to scenario blocks
  and writes deterministic CSV/Markdown reports.

### Serious game

- Verified dual 3D replay: pre-saved optimal assets plus JIT/cached player
  assets, linked play/scrub controls, and compacted machine timelines.
- Full three-level tournament/fairness coverage through MKRF → Gavin → Knife
  Creek.

### FEMIC ground support

- `fhops scenario lidar ground-summary` validates a FEMIC
  `femic.ground-summary.v1` CSV against a scenario.
- `fhops scenario lidar ground-support` emits a read-only support report.
- Scenarios may reference a ground-summary CSV through the optional
  `ground_support` section.

## Compatibility and limits

- Existing 1.0/1.1/1.2 scenario contracts remain supported. The new
  `ground_support` scenario section and Studio `salvage` block are optional.
- Results can change where CTL forwarder/harvester roles or calibrated
  load/unload timing are used.
- Salvage retention is a reference curve, not a BC-specific,
  species-specific, grade, or market model.
- Studio comparison economics are proportional planning views, not ownership,
  repair, fuel, finance, or market accounting.
- The serious game remains a deterministic training exercise, not an
  operational decision tool.
- No public authentication is added; the web UI remains local/instructor
  controlled unless deployed behind an external access layer.
