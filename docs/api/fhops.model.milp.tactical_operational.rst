``fhops.model.milp.tactical_operational`` Module
================================================

Pyomo builder and solver driver for the Phase 6 TOPM-inspired tactical–operational MILP. The model
supports continuous, semi-continuous, and whole-block harvest modes; product flows; facility
inventories; purchases; optional roads/silviculture/fleet investment; and cost/profit/NPV
objective profiles.
