# Knife Creek stand inventory

This directory contains the deterministic synthetic stand inventory for
`kc_57254551`, generated by `scripts/generate_game_inventory.py` from the
IDF Cariboo PSP Weibull regression.

- VRI polygon: `POLYGON_ID 57254551`, EPSG:3005
- Area: 35.952623 ha
- VRI target: 479 live stems/ha, 19.10182 m²/ha basal area, 29.2 m height
- Generated stand: 17,221 trees
- Harvested subset: 10,333 trees (`trees.csv`)
- Residual subset: 6,888 trees (`residual_trees.csv`)
- Seed: `57254551`
- Selection-cut removal fraction: 0.60
- QMD target: 22.533 cm (VRI basal area and stems/HA)
- QMD realized: 22.543 cm

The DBH distribution is a Weibull regression conditioned on QMD/TPA from the
IDF Cariboo PSP sample. Height is FD allometry calibrated to the VRI projected
height. Placement is deterministic Poisson inside the VRI polygon. The
harvest/residual split is a synthetic selection-cut allocation, not a
prescription.

Both CSVs validate against `fhops.tree.inventory.v1`; the harvested inventory
is pinned in `../../levels/kc_57254551/scenario.yaml`.

The residual list is for careful-logging residual-damage accounting and
visualization. It is not processed by the tree system. The exact care/damage
mapping is server-side; see `src/fhops/game/careful_logging.py`.
