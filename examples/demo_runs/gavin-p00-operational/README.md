# Gavin Lake P00 operational feasibility window

This is an operational screening handoff of the first ten-year Gavin policy period. It is not a
field-calibrated machine schedule.

## Inputs

- 192 blocks from `gavin-policy` period P00
- 505.14 ha
- 175,533.16 m³ strategic volume
- 365-day operational window
- five machines: feller-buncher, two grapple skidders, processor, loader
- eight screening landings
- 1,000 m³/day per assigned machine — a screening assumption, not a calibrated rate

## Result

- all 192 blocks completed
- 175,533.16 m³ produced
- makespan: 315 days
- sequencing violations: 0
- zero remaining work

The result says the strategic P00 volume is operationally feasible within the screening
assumptions. It does not prove field feasibility: rates, landings, roads, and haul are simplified.
