# Gavin Lake public policy target plan (draft)

This run is a WS4 target-screen plan for the full Gavin Lake estate. It is a public scenario
choice, not an approved management plan.

## Policy targets

- harvest floor: 174,000 m³ per 10-year period
- growing-stock floor at period 30: 600,000 m³
- even-flow band: ±4%
- 300-year horizon, 30 ten-year periods

The policy is a feasible screen derived from the existing public WS4 target/LTSY evidence and the
baseline behaviour. The unmodified legacy LTSY target set could not meet its 1,277,067 m³
growing-stock floor.

- **61 of 61 targets met**
