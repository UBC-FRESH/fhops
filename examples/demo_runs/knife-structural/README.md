# Knife Creek structural full-block pilot

This run exposes all 160 Knife Creek VRI blocks in the FHOPS console using the existing
WS4 spatial dataset. It is a **structural pilot**, not an approved management plan.

## Coverage

- 160 blocks
- 3,481.77 ha
- 157 eligible blocks scheduled
- 3 blocks retained on the map but unscheduled because the dataset has no treatment option
- 546,222.9 m³ in the structural first-entry schedule
- EPSG:3005 geometry
- no public net-revenue account; none fabricated

## Source

```text
/srv/shared-data/gep/ws4/femic/external/femic-afrf-knifecreek-instance
  ws4/dataset_kc_spatial_v3
  data/inventory/vri_2025_kc.gpkg
  data/boundaries/knife_creek_sup_S15382.gpkg
```

The structural schedule applies one GWM selection entry per eligible block, staggered across
offsets 0–29. It is the first complete spatial exposure of the existing dataset, not the
reviewed 30-year selection plan. The missing approved schedule and public financial account
remain explicit caveats in the run summary.
