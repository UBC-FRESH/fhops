# MKRF low-44 P01 — 30-day FHOPS haul Phase I/II

This is an actual FHOPS hauling run, not the public-geography truck screen.

## Scope

- 30-day screening horizon from MKRF low-44 P01
- 110 blocks
- one sort yard
- 12 trucks
- Phase I solved with HiGHS
- Phase II/III day 1 solved with simulated annealing
- 1,110 truckloads / 49,934 m³ delivered in the 30-day flow plan
- 37 loads scheduled on day 1
- 12 trucks used

## Caveats

This is a 30-day screening horizon, not a full-year haul plan. The scenario uses the MWP-style
screening loader/yard capacities and a single Vancouver-yard destination; it does not represent
the actual road network, mill queues, or contractor shifts.
