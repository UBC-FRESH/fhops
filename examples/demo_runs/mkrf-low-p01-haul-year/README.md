# MKRF low-44 P01 rolling full-year haul

Twelve rolling 30-day FHOPS Phase I windows for the low-44 P01 scenario.

- 110 blocks
- 20 trucks per window
- 832 m³/day demand
- aggregate delivered: **303,765.7 m³**
- aggregate truckloads: **8,295**
- 12 monthly status: feasible
- monthly detail in `provenance.json`

This is a rolling Phase I aggregation, not a single 365-day MILP. Phase II/III day samples are
separate.
